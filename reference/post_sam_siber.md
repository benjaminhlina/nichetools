# A `list` of the posterior estimates of \\\mu\\ and \\\Sigma\\ from `{SIBER}`

Posterior estimates of \\\mu\\ and \\\Sigma\\ using the
`demo.siber.data.2` data set from
[SIBER](https://cran.r-project.org/package=SIBER). This `list` is
produced using the function
[`siberMVN()`](https://rdrr.io/pkg/SIBER/man/siberMVN.html) from
[SIBER](https://cran.r-project.org/package=SIBER).

## Usage

``` r
post_sam_siber
```

## Format

A `list` with estimates of \\\mu\\ and \\\Sigma\\ for each species and
group.
